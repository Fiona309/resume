# A4 简历排版器

完全在浏览器本地运行的单页 A4 简历编辑器。版式依据参考简历复刻，并预置了费婉燕简历中的内容与证件照。

在线使用：<https://fiona309.github.io/resume/>

## 启动

双击 `启动排版器.command`，或在本目录运行：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 使用

- 左侧“简历版本”保存一份母版和任意数量的岗位版本；新岗位版本默认复制母版，之后互不影响。
- 每个岗位版本可独立填写公司、岗位和完整 JD，切换版本时自动恢复对应内容。
- 直接点击 A4 纸面上的文字编辑，修改会自动保存在浏览器 `localStorage`。
- 左侧可导入/导出约定格式 Markdown；导入只替换内容，不改变版式。
- 右侧可切换楷体、宋体、仿宋、黑体和苹方，并实时调整正文字号、章节横线粗细；点击某条段落后可只改这一行的序号，模块默认样式收纳在折叠区内。
- 画布上方集中提供字体、行距、字号和横线；右上角固定显示 A4 页面检查，无需滚动即可查看。
- 右侧保留选区加粗、斜体、字号增减、插入箭头、撤销、符号样式和照片工具，不重复显示全局排版控件。
- “新增板块”可添加自定义模块；将鼠标移到纸面模块标题附近，可用左侧 `＋` 添加教育、实习、项目或技能条目。
- 每条实习、项目和技能段落右侧都有“删除整行”按钮，也可先点击一行后在右侧选择“删除当前整行”；空行直接删除，非空行会先确认，下方内容自动上移并重新编号。
- 右侧上传证件照；可在“移动相框 / 调整构图”两种模式间切换，并用滑杆缩放。
- 超出 A4 单页区域时，页面底部和状态面板会指出首个溢出模块。
- 顶部可直接下载 A4 单页 PDF，无需进入浏览器打印窗口；也可导出可继续编辑的 Word `.docx` 文件。
- 编辑会自动写入浏览器本地存储；顶部“历史版本”按时间列出当前版本的本地快照，可选择回退；完整备份包含母版、所有岗位版本、JD、照片和样式。
- PDF 与 DOCX 可在浏览器内提取文字并转换为 Markdown 或 JSON；扫描版 PDF 需要先进行 OCR。

## 隐私

应用无后端、无外部依赖、无网络请求。文字、设置和上传照片仅保存在当前浏览器中。
